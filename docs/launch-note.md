Agent System Design helps you decide whether an agent system is warranted, then write the design before building it. The line is: design the right agent system, not just more agents.

This repository is the English full edition. The Chinese full edition of the same methodology is https://github.com/geniusjia666/agent-system-design-cn. They are two language editions, not two products. The shared methodology version is 0.1.0. That number is not a release.

The method has seven steps and four tiers: Prompt, Workflow, Single Agent, and Multi-Agent. Ordinary code can end the design early. It is not a fifth tier. A multi-agent split needs a real isolation reason. Not every larger design needs one. Twenty-one patterns are a retrieval index, not a single official standard. A twenty-one-dimension review scores a document when someone actually reviews it. It is not a performance metric. Notes on ADK, LangGraph, CrewAI, and AutoGen are mapping scaffolds, not tested integrations.

Install is a copy into the skill directory your host documents. There is no universal one-line install. A 2026-11-10 check confirmed the Cursor copy layout and did not verify that Cursor discovered or ran the skill. The record is [host-check.md](host-check.md).
