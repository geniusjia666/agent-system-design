# Provenance

[README](README.md) · [Sync notes](SYNC.md)

This repository is the English full edition of Agent System Design, methodology version [0.1.0](VERSION). The Chinese full edition of the same methodology is [agent-system-design-cn](https://github.com/geniusjia666/agent-system-design-cn). The Chinese text is not stored here.

The English skill was imported from the English zip archive supplied for publication. The archive contained Markdown and JSON only. Nothing in it was executed. `__MACOSX/` entries and AppleDouble `._*` sidecar files were discarded. The content entries did not include `.DS_Store`.

| Archive role | Published directory | Files | What changed |
|---|---|---|---|
| English skill | [skills/agent-system-design](skills/agent-system-design/SKILL.md) | 14 | Placement only. Bytes unchanged. |

[scripts/source-manifest.json](scripts/source-manifest.json) stores the SHA-256 and byte size of those 14 files (370,817 bytes). [scripts/validate_repo.py](scripts/validate_repo.py) fails if a skill file drifts from that record. The checker does not require Chinese files.

[LICENSE](LICENSE) is the MIT license from the repository's initial commit: Copyright (c) 2026 Skyler. It was not rewritten. The skill files do not add a separate author line. The GitHub owner of this repository is geniusjia666. Do not replace the copyright line in `LICENSE` unless the copyright holder does.

An earlier commit on the publication branch also carried a Chinese tree. That tree was removed so this repository stays the English edition. Removing it did not change the English skill bytes.

Repository README, the worked example, contribution notes, version and sync notes, and the validator were written for this publication. They are not part of the imported skill byte count. Version 0.1.0 names the methodology edition shared with the Chinese repository. It is not a git tag and not a GitHub Release.
